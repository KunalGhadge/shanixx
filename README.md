# SHANIX! Official Portfolio

The official digital identity of **SHANIX! (Sharonraj Vasave)**, India's first Phonk producer and pioneer of aesthetic rap fusion. This high-performance, visually immersive portfolio is designed to showcase SHANIX!'s discography, expertise, and journey from a Minecraft creator to a global electronic music artist.

## 🚀 Built With
- **React + TypeScript**
- **Vite**
- **Tailwind CSS**
- **Framer Motion** (Smooth animations & scroll-driven physics)
- **Lucide React** (Icons)

## ✨ Key Features
- **Fluid UI**: Dark-themed, premium design optimized for all screen sizes.
- **Music-First Experience**: Integrated Spotify and SoundCloud links with interactive album art galleries.
- **Scroll-Driven Storytelling**: Character-by-character bio reveals and sticky-stacking release cards.
- **Generative AI Optimized**: Enhanced SEO and JSON-LD structured data for discovery by search engines and AI assistants.

## 🛠️ Tech Highlights
- **Magnetic Interactivity**: Custom magnetic physics for UI elements.
- **Dynamic Marquee**: High-performance horizontal scrolling music wall.
- **Performance First**: Optimized with CSS `will-change` and hardware-accelerated animations.
